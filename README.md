### 🚀 Featured Projects

#### ⚙️ [InternOps — Enterprise Workforce Management Platform](https://github.com/sanjayjakhar/InternOps)
> **Stack**: `React` • `Node.js (Fastify)` • `PostgreSQL` • `Redis` • `Python (FastAPI)` • `Socket.IO` • `Google GenAI`
- **Architected 5-Tier RBAC**: Designed hierarchical permissions (`Admin → Senior TL → TL → Captain → Intern`) ensuring complete data isolation and zero cross-tier leakage.
- **Real-Time Engine**: Built automated attendance tracking, multi-level proof-of-work verification, and live notification streams via **Socket.IO**.
- **GenAI Integration**: Automated certificate generation with Google Generative AI; reached **92% test coverage**, **99.95% uptime**, and supported **500+ concurrent active users**.
- 🔗 **Repo**: [sanjayjakhar/InternOps](https://github.com/sanjayjakhar/InternOps)

---

#### 🤖 [RecruitAI — AI-Powered Autonomous Recruitment Agent](https://github.com/sanjayjakhar/RecruitAI)
> **Stack**: `Next.js` • `Groq LLM API` • `PostgreSQL (Neon)` • `Nodemailer` • `jsPDF` • `Vercel`
- **Automated Resume Screening**: Developed an intelligent agent that parses resumes via `pdf-parse` and evaluates candidates against job specs in real time with the **Groq LLM API**.
- **Automated Pipeline**: End-to-end recruiter workflow with automated interview scheduling, instant candidate scoring, and email notifications via **Nodemailer**.
- **Evaluation Reports**: Generated downloadable PDF candidate evaluation cards dynamically using `jsPDF`, cutting manual screening overhead significantly.
- 🔗 **Repo**: [sanjayjakhar/RecruitAI](https://github.com/sanjayjakhar/RecruitAI)

---

#### 🎟️ [Integrated Event Management System (IEMS)](https://github.com/sanjayjakhar/Event-Management-System)
> **Stack**: `React.js` • `Node.js` • `Express.js` • `MongoDB` • `JWT` • `Bcrypt`
- **Full-Stack Ticketing & Booking**: Allowed users to register, browse, and book events seamlessly without third-party payment dependencies.
- **Admin Control Center**: Built an intuitive organizer portal to create events, define ticket caps, set pricing tiers, and manage bookings.
- **Robust Security**: Enforced JWT and bcrypt encryption with mandatory **Email OTP verification** and responsive accessibility across mobile and desktop.
- 🔗 **Repo**: [sanjayjakhar/Event-Management-System](https://github.com/sanjayjakhar/Event-Management-System)
